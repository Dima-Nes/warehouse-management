## 🎯 Назначение и ключевые возможности

1. **Ролевое разграничение доступа (RBAC):**
   - **Администратор (`admin`):** полный доступ к системе, управление пользователями и системными настройками.
   - **Менеджер (`manager`):** работа с поставщиками, управление заказами, аналитические отчёты.
   - **Сотрудник склада (`warehouse_staff`):** оформление приходных, расходных и внутренних перемещений товаров.

2. **Складской учёт и номенклатура:**
   - Ведение справочников товаров, категорий и единиц измерения.
   - Учёт остатков с привязкой к ячейкам/зонам хранения.
   - Инвентаризация и списание товаров.

3. **Работа с поставщиками и закупками:**
   - Реестр поставщиков, условия поставок и контакты.
   - Формирование заказов на пополнение запасов.

4. **Аналитика и статистическое прогнозирование:**
   - Интерактивный дашборд с ключевыми метриками (KPI).
   - Графики динамики спроса и остатков на базе Chart.js.
   - Алгоритм предиктивного расчёта потребности в дозаказе на основе скользящих средних.
   - Экспорт отчётов в форматы Excel (XLSX) и PDF.

## 🚀 Установка и локальный запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Dima-Nes/warehouse-management.git
cd warehouse-management
```

### 2. Создание и активация виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate  # Для macOS/Linux
# venv\Scripts\activate   # Для Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка базы данных
Убедитесь, что сервер **PostgreSQL** запущен и создана база данных:
```sql
CREATE DATABASE warehouse_db ENCODING 'UTF8';
```

### 5. Применение миграций
```bash
python manage.py migrate
```

### 6. Создание администратора
```bash
python manage.py createsuperuser
```

### 7. Запуск сервера разработки
```bash
python manage.py runserver
```

Приложение будет доступно по адресу: **http://127.0.0.1:8000/**
